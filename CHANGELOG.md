## 0.0.1

* Initial plugin release.
* Supports i-mobile SDK initialization, interstitial ads, banner / inline ads, and ad lifecycle events.
* The proprietary Android and iOS SDK binaries are not distributed with this package.
* Added app-side native SDK placement instructions for Android and iOS.
* Added `.pubignore`, `.gitignore`, a publication safety check, and GitHub Actions validation to prevent accidental SDK redistribution.
